## Notes

- The integration test was verified against a LocalStack S3 endpoint (the MinIO image was not reachable
  from this environment); the test only needs a standard S3-compatible endpoint.
- Deviations from the plan:
  - The filter matcher follows rsync exactly, including that an excluded directory prunes its contents
    and that an included directory only keeps the traversal going.
  - `--exclude`/`--include` order is recovered from the raw command line, because kong keeps the two
    lists apart.
  - The destination of a single source file is the file itself, the way rsync treats it.
  - The in-memory driver lives in `internal/storage/memory` so that it can be reused by other tests.
